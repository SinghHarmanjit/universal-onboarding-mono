# Phase 1: API Contracts

## SSE Stream Extension (`GET /query`)

The Server-Sent Events (SSE) stream continues to emit standard events (`chunk`) for the detailed conversational response from the agent (either the detailed RAG answer or a clarifying question asked by the Supervisor Agent). At the end of the chain, the Supervisor Agent emits the new `summary` data points.

### Existing Events (Context)

- `chunk`: Streams the detailed conversational answer from the RAG pipeline or a clarifying question generated by the Supervisor Agent.
- `citations`: An array of `Citation` objects directly retrieved and emitted by the RAG backend.

### New Events

When the Supervisor Agent completes its decision cycle, it will emit a `summary` event alongside the standard stream closure. The `citations` in this event are passed through directly from the RAG backend.

```json
{
  "type": "summary",
  "data": {
    "rewritten_query": "The rewritten question based on context",
    "short_answer": "The generated short summary of the detailed RAG answer",
    "open_questions": [
      {
        "heading": "Question topic",
        "paragraph": "Detailed question context",
        "clarifying_question_asked": "The clarifying question the agent streamed to the user, if applicable",
        "requires_clarification": true,
        "status": "pending_clarification" // e.g., 'pending_clarification' or 'ready_for_consultant'
      }
    ],
    "citations": [
      {
        "id": "1",
        "title": "Docs",
        "url": "https://..."
      }
    ]
  }
}
```

## Supervisor Agent Graph

The LangGraph implementation for the Supervisor Agent defines the following nodes and edges:

**Nodes**:
- `Supervisor`: Analyzes user input and routes traffic.
- `RAG_Pipeline`: Executes the retrieval-augmented generation.
- `MEDPIC_Evaluator`: Reviews conversation history against MEDPIC framework and generates clarifying questions.
- `Sales_Handoff`: Formats open questions and business case for the Reap Consultant.

**Edges**:
- `Supervisor` -> `RAG_Pipeline` (if factual answer needed)
- `RAG_Pipeline` -> `Supervisor` (returns RAG output for evaluation)
- `Supervisor` -> `MEDPIC_Evaluator` (if more business context is needed or open questions require clarification)
- `Supervisor` -> `Sales_Handoff` (if questions are unanswerable and ready for consultant)
- `Supervisor` -> `END` (when response is complete)
